# LocalDrop Web (PairDrop-style)
Run locally:  npm install && npm start   -> open http://localhost:3000 (use your PC's LAN IP from a phone on the same Wi-Fi)
Deploy free:  push this folder to GitHub, then create a "Web Service" on a free Node host (e.g. Render). Build: npm install, Start: npm start.
Privacy: the server only relays tiny connection messages. Files travel directly browser-to-browser (WebRTC, encrypted). Nothing is stored.
